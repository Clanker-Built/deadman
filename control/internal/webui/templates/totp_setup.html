Add this account to an authenticator app: Aegis (Android, recommended), Raivo (iOS), KeePassXC (desktop), 1Password, Bitwarden, Authy, Google Authenticator. Use whatever you already trust.

1. Add the account

Most apps offer a scan QR code or enter setup key option. This page does not render a QR — Tor Browser is brittle with inline images and we want to keep the CSP strict. Use the manual entry:

Account: {{.UserEmail}}

Type: Time-based (TOTP), 6 digits, 30-second period, SHA-1

Setup key: {{.TOTPSecret}}

otpauth:// URL (for apps that paste a URL)

{{.TOTPURI}}

2. Save your recovery codes

Each code is single-use. If you lose your authenticator, you can log in with one code and then set up a new authenticator. Save them now — they will not be shown again.
