On-demand pg_dump snapshot of the control-plane database. Output is --format=custom (readable with pg_restore), gzip-compressed, uploaded to object storage. Retention keeps the {{.Admin.BackupKeep}} most recent successful backups; older OK backups are deleted from the bucket automatically. Restore is a CLI operation — a one-click restore is how you lose production data. See Runbook §8.
