Delete your account

Permanent. Deletes your user row, all passkey credentials, devices, sessions, policies, bundle metadata, and destinations from the server's database. Bundle ciphertext in object storage is not automatically purged — operators with bucket access must delete it separately if asked.

Audit events you generated remain in the hash-chained ledger with your user ID intact (the chain must not be broken). They no longer link to a user row, but the events themselves persist for integrity reasons. An account.deleted event is appended at deletion time.

Requires a recent step-up authentication (within 5 minutes). If yours is stale you'll be redirected to re-confirm first.
